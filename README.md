# ASCENSÃO OS PRO (PWA Offline)

PWA mobile-first offline para execução diária com foco em múltiplas áreas de evolução pessoal.

## O que foi reforçado nesta versão
- Abas expandidas por área: Identidade, Shape, Beleza, Financeiro, Acadêmico, Espiritual, Social, Internet, Intelectual, Mental e Organização.
- Score por área (0-100) com ações rápidas de progresso e feedback imediato (som + vibração + XP).
- Planner diário atualizado para refletir áreas-chave e modo recuperação.
- Modo estrito por janela de horário com penalidade de integridade.
- Exportações TXT/JSON/CSV e persistência offline via IndexedDB/localStorage.

## Executar local
```bash
python -m http.server 4173
```

Acesse: `http://localhost:4173`.
## Nota sobre PR
- Ícones do PWA foram convertidos para SVG (texto) para evitar bloqueios de plataformas/ferramentas que não aceitam arquivos binários no fluxo de PR.
